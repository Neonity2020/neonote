# 块编辑器

编辑器的交互模型是"**每一行是一个块**"：块之间可以独立换行、拆分、合并、拖动、转换类型。

---

## 页面标题与图标

- 标题是页面的一部分，存在 `pages.title` 字段，**不占用块**。
- 标题输入框是 `textarea`，随内容自动增高，38px 粗体。
- 标题下方的图标按钮点开**表情选择器**：64 个常用 emoji，可一键"移除图标"。
- 标题留空时显示占位符「无标题」，但**实际存储的是空字符串**，不是占位符文本。

> 页面图标存的是 emoji 本身（如 `👋`），没有单独的资源表。

---

## 块的构成

一个块由三部分组成（`packages/shared/src/index.ts:68`）：

| 字段 | 含义 |
| --- | --- |
| `type` | 块类型，12 选 1 |
| `content` | 内容对象，形状随类型变化 |
| `position` | 在页面内的排序位置（浮点数） |

`content` 目前有四个可能的键：

| 键 | 用于 |
| --- | --- |
| `text` | 绝大多数块；表格块存纯文本摘要 |
| `checked` | 仅 `todo` 块 |
| `src` | 仅 `image` 块，值为 `nc-asset://asset/<id>` |
| `table` | 仅 `table` 块，值为 `{ rows: string[][], header: boolean }` |

## 输入与保存

文本块用 `contentEditable` 实现，输入事件直接读取 `textContent`：

```
onInput → updateBlockLocal(本地 state 立即更新)
        → scheduleSave(400ms 防抖)
        → window.api.updateBlock(落库)
```

- **防抖窗口 400ms**（`packages/renderer/src/store.ts:5`），连续输入只在停顿后写一次库。
- 同一块的多次编辑会**取消前一次待执行的写入**，不会堆积。
- 切换页面、删除页面、AI 刷新数据前会调用 `flushSaves()`，把未落库的编辑强制写回。
- 文本块禁用拼写检查（`spellCheck={false}`），中文输入不受影响。

> **为什么用 `contentEditable` 而不是 `<textarea>`**：需要支持行内混排、选区操作、粘贴图片。
> 代价是必须手动维护 DOM 与 state 的同步，见下方"外部更新"。

## Enter：拆分块

在任意文本块按 `Enter`（不带 Shift）：

1. 光标位置之前的文本留在当前块；
2. 光标之后（含光标处插入点）的内容进入新块；
3. 新块紧接在当前块之后，光标落在新块开头。

**类型继承规则**：从无序列表、有序列表、待办事项拆分出的新块**继承同类型**；
其他类型拆出的是**正文块**。

**空列表项特例**：在空的无序列表 / 有序列表 / 待办块上按 `Enter`，
该块**就地退回正文块**，不会新建空块。这与 Notion 的行为一致。

## Backspace：合并块

光标位于块首（offset 为 0）时按 `Backspace`：

| 情况 | 行为 |
| --- | --- |
| 当前块为空 | 删除当前块，焦点移到上一块 |
| 当前块为空且是第一个块 | 退回正文块类型（不删除） |
| 当前块非空，上一块是普通文本块 | 当前块文本**追加到上一块末尾**，删除当前块，焦点落在合并点 |
| 上一块是**分割线** | 删除分割线，焦点留在当前块开头 |
| 上一块是**图片**或**表格** | **不合并**（这两类块没有文本可承接），只把焦点移到上一块 |

光标不在块首时，`Backspace` 是普通的删除字符。

## 方向键

| 按键 | 行为 |
| --- | --- |
| `↑` 光标在块首 | 焦点移到上一个文本块的开头 |
| `↓` 光标在块尾 | 焦点移到下一个文本块的开头 |
| `Tab`（普通文本块） | 被拦截，不缩进。文本块目前**不支持嵌套层级** |

方向键在块中间时不移动焦点，由浏览器处理。

## 拖拽排序

- 鼠标移到块上，左侧出现两个按钮：**⊕（在下方添加块）** 和 **⠿（拖动排序手柄）**。
- 只有按住 **⠿** 才能拖动，块本身不能拖。
- 拖动激活距离 4px，避免误触。
- 拖动时原位置半透明显示，落下后顺序立即生效并落库。

> 页面的拖拽是**另一套逻辑**（可改变层级），详见 [页面与层级](pages.md)。

---

## 底部空白区

编辑器下方保留 30vh 的空白可点击区域。点击它：

- 如果最后一块是**空正文块**，直接把光标放进那一块；
- 否则在末尾**追加一个新的空正文块**并聚焦。

这样在页面末尾继续写作不需要先滚动到最后一个块。

## 外部更新与光标保持

有两处会从外部改写块内容：

1. **AI 助手改了数据库** → 主进程广播 `ai:notes-changed` → 前端整体重载页面和块；
2. **切换页面回来** → 重新从数据库拉取块列表。

同步策略（`packages/renderer/src/components/BlockItem.tsx:97`）：

- 块**正在被编辑**时，不打断用户，不覆盖 `textContent`；
- 块**不在焦点**且 `textContent` 与 state 不一致时，才写回 DOM。

表格单元格采用同样策略：正在编辑的单元格不会被外部数据覆盖。

---

## 编号列表的自动编号

有序列表的序号是**渲染时计算**的，不入库：

- 连续的有序列表块序号递增；
- 遇到任何非有序列表的块，计数器**归零**。

因此在中间插入一个段落会打断编号序列，这属于预期行为。
