# AI 助手

右侧可展开面板，由本机 **Pi SDK** 驱动，直接读写你的笔记。

---

## 打开面板

点编辑器右上角的 **✨** 按钮展开。面板宽 320px，包含：

```
┌──────────────────────────────┐
│ ✨ AI 助手   provider / model │  ← 头部，显示当前模型
├──────────────────────────────┤
│ ⚠ 初始化失败 + [重试]          │  ← 仅在出错时出现
├──────────────────────────────┤
│ 📄 上下文: 👋 标题 · 12 个块   │  ← 上下文状态条
├──────────────────────────────┤
│  对话消息流                    │
│  · 思考过程（可折叠）           │
│  · 工具调用徽标                 │
├──────────────────────────────┤
│ [输入框]              [发送]    │
└──────────────────────────────┘
```

---

## 提问

- `Enter` 发送，`Shift+Enter` 换行。
- 发送中输入框右侧变成 **■**（停止），可随时中断当前生成。
- 空输入不能发送。

### 输出内容

- **正文**：模型的回答，流式逐字追加。
- **思考过程**：模型的推理内容，收在可折叠的 `<details>` 里。
- **工具徽标**：每次工具调用显示一个胶囊，带图标 + 中文标签 + 状态
  （进行中转圈 / 成功打勾 / 失败红叉）。
- **通知**：系统级消息居中显示，例如「设置已更新,对话上下文已重置」。

## 页面上下文

上下文状态条实时显示当前会带上的内容：

| 显示 | 含义 |
| --- | --- |
| `已关闭(可在设置中开启)` | 设置里关闭了自动附带 |
| `👋 标题 · 12 个块` | 当前页面 + 块数量 |
| `无打开的页面` | 没有选中页面 |

开启时，每次提问会把当前页面的**标题、每个块的 id、类型、文本、待办勾选状态**一起发给模型。

这样 AI 可以**直接用块 id 修改内容**，省掉一次读取调用。

> **上下文是快照**。发送之后你再手动编辑页面，模型手里的仍是发送那一刻的内容。
> AI 自己也收到了"怀疑内容已变就重新读取"的指令，可以调用 `notes_read_page` 刷新。

上下文采用**指纹去重**：页面 id、标题、所有块的 id/类型/文本/勾选状态拼成一个指纹，
指纹不变就不重复注入，避免每轮对话堆叠同一份上下文。

## 模型

模型列表来自本机 `~/.pi/agent` 的配置，**只显示已配置凭据的模型**。

在 **设置 → AI 助手** 里选择：

- **跟随 pi 默认**（`model = null`）—— 让 Pi 自己挑。
- 具体模型 —— 存成 `provider/id` 字符串。

切换模型**立即生效并保留当前对话**（主进程调用 `session.setModel`）。

修改「附加指令」或「自动附带页面」这类**改变系统提示词**的设置会**重置对话上下文**，
因为提示词变了，旧会话的上下文不再匹配。

## 工具

AI 有一套受限的工具集，只能操作笔记，**不能访问文件系统或网络**：

| 工具 | 作用 |
| --- | --- |
| `notes_list_pages` | 列出所有页面 |
| `notes_read_page` | 读取某页面的全部块 |
| `notes_search` | 搜索标题与块正文 |
| `notes_create_page` | 新建页面 |
| `notes_append_blocks` | 向页面末尾追加块 |
| `notes_update_block` | 修改块 |
| `notes_delete_block` | 删除块 |

详细参数见 [笔记工具集](../ai/tools.md)。

### AI 改了笔记之后

只要 AI 调用了**写操作**工具（建页面 / 追加 / 改 / 删），主进程就会广播
`ai:notes-changed`，前端收到后**重新从数据库加载**页面和块，编辑器内容随之更新。

在重新加载前，前端会先把**未落库的本地编辑强制写回**，避免 AI 的改动被旧快照覆盖。

## 错误与重试

面板顶部出现红色错误条时（初始化失败），提供 **「重试」** 按钮：

1. 丢弃当前会话（可能是在坏环境下建立的）；
2. 重新获取状态。

常见错误与处理见 [AI 排障](../ai/troubleshooting.md)。

---

## 重置对话

**设置 → AI 助手 → 重置对话**，或在设置里勾选「恢复默认设置」。

重置会丢弃整个会话（对话历史 + 上下文），**不影响笔记内容**。下次提问时按最新设置重建会话。

---

## 安全边界

- 内置工具（`read` / `bash` / `edit` / `write`）**全部禁用**。
- Pi 的用户级扩展、技能、提示词模板**全部不加载**（`noExtensions` / `noSkills` /
  `noPromptTemplates` / `noContextFiles` 均为 `true`）。
- 系统提示词明确告知模型：你只能通过工具操作笔记，不要假装能访问文件系统或网络。
- 删除操作要求模型**执行前向用户确认**，除非用户已明确表达删除意图。
- **凭据不经过本应用**：模型调用由 Pi SDK 在主进程内直接发起，
  应用只读取 `~/.pi/agent` 的既有配置，不存储任何 API Key。
