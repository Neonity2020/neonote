# 设置

点侧边栏右下角 **⚙** 打开。弹窗分左右两栏：左侧是分区导航，右侧是内容。
`Esc` 或点击弹窗外区域关闭。

---

## 存储与生效机制

设置按**分区**（section）存储，每个分区是 `settings` 表里的一行：

| 分区键 | 内容 |
| --- | --- |
| `theme` | 主题模式 |
| `editor` | 正文字号、内容宽度、空白页背景图 |
| `ai` | 模型、上下文开关、附加指令 |

关键约定：

- **主进程是唯一裁决者**。任何写入都会先经过校验（`sanitize`），落库后再把**最终生效值**返回前端。
  前端拿到的永远是合法值，不会出现"界面显示 A、实际生效 B"。
- **坏值自动回落默认**，不会因为一条损坏的记录让应用无法启动。
- 保存后主进程**广播** `settings:changed` 给所有窗口，多窗口场景下保持一致。
- 读取时单个分区解析失败会被**忽略**（回落到默认），不影响其他分区。

## 外观

### 主题

三选一：

| 选项 | 行为 |
| --- | --- |
| 浅色 | 固定浅色 |
| 深色 | 固定深色 |
| 跟随系统 | 随操作系统的深浅色外观自动切换 |

"跟随系统"通过 `window.matchMedia('(prefers-color-scheme: dark)')` 监听变化，实时响应。

应用通过在 `<html>` 上切换 `dark` class 来启用深色模式（Tailwind 的 `darkMode: ['class']`），
同时设置 `color-scheme` 让原生滚动条、表单控件也跟随。

> 窗口底色在创建时就按当前主题设定（`src/main/index.ts:41`），避免深色模式下启动闪白。

### 正文字号

四档预设：**14 / 15 / 17 / 19** px，默认 15。

影响段落、列表、待办、引用等正文类块的文字大小，同时决定行高与排版节奏。
标题、代码块有各自的固定字号，**不随此设置变化**。

实现上通过根节点 CSS 变量 `--editor-font-size` 下发，样式表里的 `.block-body` 消费它。

### 内容宽度

三档预设：

| 档位 | 最大宽度 |
| --- | --- |
| 窄 | 640px |
| 标准 | 768px |
| 宽 | 1080px |

通过 CSS 变量 `--editor-max-width` 下发，作用于编辑器容器。

### 空白页背景图

开关，默认开启。

开启后，**还没写内容的页面**会在正文后面显示一张插画背景：

- 判定条件是页面**没有标题**、**只有一个空正文块**；
- 一旦输入了标题或正文，背景立刻消失；
- 深色模式下背景会被压得更暗，不会干扰文字。

关闭后任何页面都不显示背景。设置改动**立即生效**，不需要重启。

> 背景图是打包在渲染层里的静态资源（WebP，约 200 KB），与用户存到数据目录的图片无关。

## AI 助手

### 模型

- 搜索框按模型 id、provider、显示名过滤。
- 列表按 provider、id 排序，最多渲染 120 条（超出提示"还有 N 个结果"）。
- 「刷新」按钮重新读取模型列表。
- 选中的模型存成 `provider/id`。
- **「跟随 pi 默认」**对应 `model = null`。
- 换模型**保留当前对话**；但切回「跟随 pi 默认」会**重建会话**（`setModel()` 没法取消指定模型）。

如果一个可用模型都没有，会显示红色提示和排查建议（见 [AI 排障](../ai/troubleshooting.md)）。

### 自动附带当前页面

开关。开启后每次提问自动附带当前页面的内容（标题 + 块 id + 文本）。

- **修改会重置对话**——因为它改变了系统提示词。
- 关闭时，AI 需要自己调用 `notes_list_pages` + `notes_read_page` 找到内容。

### 附加指令

多行文本框，**失焦自动保存**，最长 4000 字符（超出会被截断）。

追加到内置系统提示词之后，用于固定 AI 的语气和写作习惯。例如：

> 整理会议记录时,始终把待办抽成 todo 块,并标注负责人。

**修改会重置对话。**

### 重置对话

丢弃当前 AI 会话（对话历史 + 上下文），**不影响笔记内容**。

## 数据与存储

### 页面 / 块

显示当前页面数和块总数。提示语强调：全部保存在本机 SQLite 数据库中，**不上传任何服务器**。

### 数据库

显示数据库完整路径和体积。点「打开目录」在系统文件管理器中打开数据目录。

### 图片资源

显示 `assets/` 目录路径、文件数量和总体积。同样支持「打开目录」。

### 恢复默认设置

**两次点击确认**（第一次按钮变成红色的「再点一次确认」，3 秒后自动取消）。

重置主题、字号与内容宽度、AI 偏好这三个分区，**不会删除任何页面或块**。
