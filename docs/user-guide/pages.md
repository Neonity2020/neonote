# 页面与层级

左侧边栏的页面树是应用的导航主干，支持**无限层级**、**折叠**、**拖拽改层级**。

---

## 页面结构

一个页面有这些属性：

| 属性 | 说明 |
| --- | --- |
| `id` | UUID，新建时生成 |
| `title` | 标题，可为空 |
| `icon` | emoji 或 `null` |
| `parentId` | 父页面 id，`null` 表示顶层 |
| `position` | 同级内的排序位置（浮点数） |

层级通过 `parentId` 表达，**没有深度上限**。

> 数据库层面**没有**自引用约束阻止把页面拖进自己的子树，
> 这个校验在业务层完成（见下文"循环保护"）。

---

## 新建页面

三种入口：

1. 侧边栏「页面」标题右侧的 **+** → 顶层页面。
2. 悬停页面行出现的 **+** → 该页面的**子页面**。
3. 页面行 `⋯` 菜单 →「新建子页面」。

新建的页面会自动带**一个空正文块**，保证打开就能输入。

---

## 重命名

- **双击**页面标题进入编辑。
- 或通过 `⋯` 菜单 →「重命名」。
- `Enter` 提交，`Esc` 放弃。
- 标题为空时列表里显示「无标题」（**占位显示，不写入数据库**）。
- 改名走 400ms 防抖落库，与块编辑一致。

---

## 折叠与展开

有子页面的行左侧显示一个箭头按钮，点击折叠/展开。折叠状态是**纯前端状态**，不落库，重新启动后默认全部展开。

折叠的行在拖拽计算中仍然参与位置测量，但**其子行不参与**——即拖拽时看不见的子树不会被算作落点。

---

## 拖拽：改顺序与改层级

侧边栏拖拽**不用** dnd-kit 的 `over` 判定，而是**自己算落点**（`packages/renderer/src/components/Sidebar.tsx:140`）。
这是为了可预测性：拖影本身仍在列表里，用 `over` 会不断抖动。

### 落点计算规则

**纵向 —— 插到哪个间隙**

逐行量出每一行的位置（跳过被拖的那一行），把指针纵坐标和各行**中线**比较，
落在第一个"指针在中线之上"的行之前。

**横向 —— 变成几级**

层级看的是**相对按下位置的横向位移**，不是指针的绝对横坐标：

```
shift = round((当前指针X − 按下时指针X) / 14)
目标层级 = clamp(原层级 + shift, 0, 锚点层级 + 1)
```

每级缩进 **14px**。这样"按住不动"保持原层级，**右移约 14px 才下沉一级**，
不会出现"随手抓在行中间就深了两级"的误判。

- 比锚点深一级 → 成为锚点的**最后一个子页面**。
- 与某个祖先同级 → 插到那一行之后。

### 视觉反馈

拖动时显示一条**插入指示线**：纵向位置 = 落点间隙，横向下缩进 = 目标层级。
拖成子页面时，目标父行会**高亮**。

### 落地后的行为

- 页面移动**先落库再整体替换前端状态**，避免前端拼树时出现与数据库不一致的中间态。
- 拖进一个**折叠的**页面时会自动展开它，否则用户看不到刚移进去的页面。
- 如果落点与当前位置完全一致，**不打 IPC**（`positionUnchanged`）。

### 循环保护

两级校验，渲染层和主进程各一道：

1. 不能拖到自己下面。
2. 不能拖到**自己的后代**下面（沿 `parentId` 链向上找）。

主进程侧会抛错：`不能把页面移动到它自己下面` / `不能把页面移动到它自己的子页面下面`。

---

## 删除

`⋯` 菜单 →「删除」。

- 删除是**级联**的：子页面及其所有块一起删除（数据库 `ON DELETE CASCADE`）。
- 前端会先在内存里算出所有受影响页面（含后代），从列表中移除。
- 如果删掉的正是当前正在看的页面，自动跳转到剩余的第一个页面。
- **不可撤销**，没有回收站。

---

## 恢复示例内容

只有标题为 **「欢迎使用 Notion Clone」** 的页面会显示这个菜单项。

- 找到该标题的页面（按创建时间取最早的一个）。
- **清空该页面所有块**，重新插入预置的示例块。
- 页面本身的 id、标题、图标**保持不变**。
- 整个替换过程在**单个事务**内完成，失败会回滚。
- 找不到欢迎页面时抛错。

---

## 排序是怎么存的

同级的顺序用 `position` 浮点数表达，详见 [数据模型](../architecture/data-model.md#位置策略)。
简单说：新建时 `position = 兄弟中最大值 + 1024`；插入到中间时取**前后邻居的中点**，
因此**插入一个同级页面不需要重写整层**。

拖拽结束后落点会被转换成"父级 + 兄弟索引"，由主进程算出新的 `position`。
