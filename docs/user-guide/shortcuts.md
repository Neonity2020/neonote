# 快捷键速查

一页看完所有键盘操作。

---

## 文本块

| 按键 | 行为 |
| --- | --- |
| `Enter` | 在光标处拆分块；列表类块继承类型；**空列表项退回正文** |
| `Shift+Enter` | 默认换行（仅代码块与表格单元格内生效） |
| `Backspace`（光标在块首） | 与上一块合并；上一块是分割线则删除它；上一块是图片/表格则只移动焦点 |
| `Backspace`（空块，块首） | 删除当前块，焦点移到上一块 |
| `↑`（光标在块首） | 焦点移到上一个文本块 |
| `↓`（光标在块尾） | 焦点移到下一个文本块 |
| `Tab` | **被拦截**，文本块不支持缩进 |
| `Ctrl/Cmd+V` | 粘贴文本；剪贴板里有图片时改为插入图片块 |

---

## 代码块

| 按键 | 行为 |
| --- | --- |
| `Tab` | 插入两个空格（缩进） |
| `Esc` | 跳出代码块，在下方新建正文块 |
| `Ctrl/Cmd+Enter` | 同 `Esc` |
| `Backspace`（内容为空） | 删除代码块，焦点移到上一块 |
| `↑` / `↓` | 在首行/末行时移动到相邻块 |

---

## 表格单元格

| 按键 | 行为 |
| --- | --- |
| `Tab` | 下一格；最后一格则新增一行 |
| `Shift+Tab` | 上一格；第一格则跳到上一行最后一格 |
| `Enter` | 下一行同列；最后一行则新增一行 |
| `Shift+Enter` | 单元格内换行 |
| `↑` | 单元格首行时跳到上一行；表格首行则跳出到上一个块 |
| `↓` | 单元格末行时跳到下一行；表格末行则跳出到下一个块 |
| `←` | 行首时跳到上一格末尾；行首第一格则跳出到上一个块 |
| `→` | 行尾时跳到下一格开头；行尾最后一格则跳到下一行第一格 |
| `Backspace`（空单元格） | 回到上一格；首格第一格不动 |

---

## 表格整体（焦点在表格而非单元格时）

| 按键 | 行为 |
| --- | --- |
| `Backspace` / `Delete` | 删除整个表格块 |
| `Enter` | 在表格下方插入正文块 |

---

## 图片块

| 按键 | 行为 |
| --- | --- |
| `Enter`（未选图） | 打开文件选择器 |
| `Enter`（已选图） | 在下方插入正文块 |
| `Backspace` / `Delete` | 删除图片块 |
| `↑` / `↓` | 移动到相邻块 |

---

## 分割线块

| 按键 | 行为 |
| --- | --- |
| `Enter` | 在下方插入正文块 |
| `Backspace` / `Delete` | 删除分割线 |

---

## 斜杠命令菜单

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 移动选中项 |
| `Enter` | 应用选中的块类型 |
| `Esc` | 关闭菜单 |

---

## 双链选择器

输入 `[[` 唤起。

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 移动选中项 |
| `Enter` / `Tab` | 插入 `[[标题]]` |
| `Esc` | 关闭选择器 |

> 查询词是 `[[` 到**光标**之间的全部内容，选中后整段被替换。

---

## 链接跳转

| 操作 | 行为 |
| --- | --- |
| 点击链接 | 跳到目标页面；目标不存在则按标题新建 |
| 点击反向链接 | 跳到来源页面，并滚动到写这条链接的那一块 |

## 表情选择器

| 按键 | 行为 |
| --- | --- |
| `Esc` | 关闭选择器 |

---

## 侧边栏

| 操作 | 行为 |
| --- | --- |
| 双击页面标题 | 进入重命名 |
| `Enter`（重命名中） | 提交 |
| `Esc`（重命名中） | 放弃 |
| 点击页面左侧箭头 | 折叠/展开子页面 |
| 拖动页面 | 改顺序；横向移动改层级 |

---

## 鼠标操作

| 操作 | 行为 |
| --- | --- |
| 悬停块 | 左侧出现 ⊕（下方添加块）和 ⠿（拖动手柄） |
| 点击 ⊕ | 在当前块下方插入正文块 |
| 拖动 ⠿ | 调整块顺序 |
| 悬停表格 | 右上角出现工具条 |
| 悬停页面行 | 出现 `⋯` 菜单和 `+` 按钮 |
| 点击页面图标 | 打开表情选择器 |
