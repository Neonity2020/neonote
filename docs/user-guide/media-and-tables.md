# 图片与表格

这两类块没有普通文本，是编辑器里最"重"的两个块类型。

---

## 图片

### 插入方式

**方式一：斜杠菜单**

1. 输入 `/` → 选择「图片」。
2. 块变成一个虚线框，提示「点击选择图片,或在任意文本块中 Ctrl+V 直接粘贴图片」。
3. 点击虚线框 → 打开系统文件选择器 → 选图。

**方式二：直接粘贴（推荐）**

在**任意文本块**中 `Ctrl+V`（macOS `Cmd+V`）粘贴剪贴板里的图片。

如果光标在文字中间，粘贴会**自动拆成三块**：

```
[文本块: 光标前的文字]
[图片块]
[文本块: 光标后的文字]
```

光标落在新生成的正文块开头。（实现见 `src/renderer/src/components/BlockItem.tsx:252`）

### 存储

- 图片被**复制**进应用数据目录的 `assets/` 子目录，文件名是 `UUID + 扩展名`。
- 块里只存一个引用字符串：`nc-asset://asset/<uuid>.png`。
- 渲染层直接把这个 URL 交给 `<img src>`，由自定义协议拦截读取本地文件。

支持的扩展名：`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp` `.svg` `.avif` `.ico`。

### 交互

| 操作 | 行为 |
| --- | --- |
| `Enter`（未选图时） | 打开文件选择器 |
| `Enter`（已选图时） | 在下方插入正文块，光标落在那里 |
| `Backspace` / `Delete` | 删除图片块，焦点移到相邻块 |
| `↑` / `↓` | 在块之间移动焦点 |

图片块**不能被文本合并**——上一块是图片时按 Backspace 只会移动焦点过去。

### 显示

- 最大高度 480px，宽度自适应，不允许拖拽。
- 图片块聚焦时有 2px 焦点环。

## 表格

表格是**纯文本**结构：二维字符串数组 + 是否启用表头。

```jsonc
{
  "header": true,
  "rows": [
    ["块类型", "说明"],
    ["文本", "段落、标题、列表、待办"]
  ]
}
```

不支持合并单元格、不支持富文本、不支持列宽调整（等分）。

### 默认尺寸

新建表格默认 **3 行 × 3 列**，`header = true`（第一行渲染为表头）。

### 单元格导航

| 按键 | 行为 |
| --- | --- |
| `Tab` | 跳到右侧单元格；已在最后一格 → **自动新增一行**并跳到新行第一格 |
| `Shift+Tab` | 跳到左侧单元格；已在第一格 → 跳到上一行最后一格 |
| `Enter` | 跳到下一行同一列；已在最后一行 → **新增一行** |
| `Shift+Enter` | 单元格内换行（不跳行） |
| `↑` | 在多行单元格的**首行**按 → 跳到上一行同列；表格首行 → 跳出到上一个块 |
| `↓` | 在多行单元格的**末行**按 → 跳到下一行同列；表格末行 → 跳出到下一个块 |
| `←` | 在行首按 → 跳到上一格末尾；行首第一格 → 跳出到上一个块 |
| `→` | 在行尾按 → 跳到下一格开头；行尾最后一格 → 跳到下一行第一格 |
| `Backspace` | 在**空的**非首格按 → 回到上一格；首格第一格不动（避免误删整表） |

> 表格整体获得焦点（不是单元格）时：`Backspace`/`Delete` 删除整个表格，`Enter` 在下方插入正文块。

### 工具栏

鼠标悬停表格，右上角出现工具条：

| 按钮 | 作用 |
| --- | --- |
| 上方插入行 | 在当前行之前插入空行 |
| 下方插入行 | 在当前行之后插入空行 |
| 左侧插入列 | 在当前列之前插入空列 |
| 右侧插入列 | 在当前列之后插入空列 |
| 表头 | 切换"第一行作为表头" |
| 删除行 | 删除当前行（只剩一行时不可删） |
| 删除列 | 删除当前列（只剩一列时不可删） |
| 删除表格 | 删除整个表格块 |

工具条只在**表格获得焦点或鼠标悬停**时出现。

### 纯文本摘要

每次表格变化，都会同时写入 `content.text`：

```
行1单元格1 | 行1单元格2
行2单元格1 | 行2单元格2
```

**用途**：让表格能被全文搜索、能让 AI 直接读懂表格内容、能被复制粘贴为纯文本。
表格没有摘要时，`notes_read_page` 之类的接口拿到的会是空文本。

### 表格块的特殊性

- 表格块**不能被文本合并**——上一块是表格时按 Backspace 只移动焦点。
- 从其他类型转成表格会生成默认 3×3 表格；从表格转走**保留数据**，方便转回来。
- 单元格内容是 `contentEditable` 的纯文本，支持换行（`Shift+Enter`）。
