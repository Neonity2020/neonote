# 数据库块

在空白正文块输入 `/数据库` 或 `/database`，选中“数据库”后按回车。

数据库默认使用表格视图，初始包含“名称”和“状态”属性。点击数据库名称或表头名称可直接重命名；在单元格内编辑记录，修改会自动保存到本地。

点击顶部“画廊”切换为自适应卡片布局，点击“表格”切回。两种视图共用同一组记录、搜索和排序。画廊将第一个文本属性作为卡片标题，其余属性显示在卡片正文中，所有字段均可直接编辑；没有文本属性时显示“未命名记录”。画廊也支持新增和删除记录、添加属性；属性重命名和删除在表格视图中操作。当前卡片不包含图片封面。

- 点击“添加属性”创建文本、数字、日期、复选框或单选属性。单选选项用逗号分隔，在创建属性时设置。
- 点击“新增记录”添加空白记录。添加后搜索条件会清空，方便编辑新记录。
- “搜索记录”匹配所有属性值；排序菜单选择属性，旁边的按钮切换升序和降序。数字属性按数值排序。
- 删除记录或属性需要确认。删除属性会同时删除所有记录中该属性的值；至少保留一个属性。
- 点击“在下方继续写作”添加正文块并将光标移入。

数据库名称、属性、记录、视图和排序设置保存在块内容中，切换页面后会恢复。搜索条件仅用于当前视图。数据库文本也会提供给现有页面搜索和 AI 阅读上下文。

当前支持表格和画廊视图；不包含看板、关联、公式、记录详情页或属性类型转换。
