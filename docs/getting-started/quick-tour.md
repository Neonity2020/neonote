# 功能巡览

5 分钟走一遍应用的全部能力。面向第一次打开应用的用户。

---

## 1. 界面分区

```
┌──────────┬──────────────────────────────────┬──────────────┐
│          │  图标 + 标题                      │              │
│  侧边栏   │                                  │  AI 助手     │
│  搜索     │  块编辑器                        │  (可展开)    │
│  页面树   │                                  │              │
│          │                                  │              │
│  设置 ⚙  │                                  │              │
└──────────┴──────────────────────────────────┴──────────────┘
```

- **左侧**：搜索框、页面树、新建按钮、底部显示页面总数和设置入口。
- **中间**：当前页面的标题和块内容。右上角有个 **✨** 按钮，点开就是 AI 助手。
- **右侧**：AI 助手面板，展开后宽 320px，贴在编辑器右边缘。

---

## 2. 写第一段内容

在页面标题下方点击，开始输入。

- 直接输入就是**正文**块。
- 输入 `/` 唤起**命令菜单**，可以切换块类型。
- 输入 `# ` + 空格，变成**标题 1**；`## `、`### ` 同理。
- 输入 `- ` 变成**无序列表**，`1. ` 变成**有序列表**。
- 输入 `[] ` 或 `[ ] ` 变成**待办事项**。
- 输入 `> ` 变成**引用**，` ``` ` 变成**代码块**，`---` 变成**分割线**。

> 完整的快捷输入对照见 [块类型参考](../user-guide/blocks.md#markdown-快捷输入)。

**按 Enter** 在光标处拆分成新块；**按 Backspace**（光标在块首）把内容并回上一块。
列表类块在空状态按 Enter 会退回正文块。

---

## 3. 插入表格

输入 `/` → 选「表格」，光标自动落在第一个单元格。

- `Tab` 跳到下一格，末格按 `Tab` 自动新增一行。
- `Shift+Tab` 回到上一格。
- `Enter` 跳到下一行；最后一行按 `Enter` 新增一行。
- `Shift+Enter` 在单元格内换行。
- 鼠标悬停表格，右上角出现工具条：增删行列、切换表头、删除表格。

表格是**纯文本**结构（不支持合并单元格），内容会同时以纯文本摘要写入块正文，
因此**可以被搜索，也能被 AI 读取**。

---

## 4. 插入图片

两种方式：

1. `/` → 选「图片」→ 点击虚线框，从系统文件选择器选图。
2. **在任意文本块里直接 `Ctrl+V`（macOS `Cmd+V`）粘贴图片**。

粘贴时如果光标在文字中间，会自动拆成三块：光标前的文字、图片块、光标后的文字。

图片文件被复制进应用数据目录，笔记里只存一个 `nc-asset://asset/<id>` 引用。

---

## 5. 组织页面

侧边栏的页面树支持无限层级。

- 点页面左侧箭头**折叠/展开**子页面。
- **双击**页面标题重命名。
- 悬停页面行出现 `⋯` 菜单：重命名 / 新建子页面 / 删除（/ 恢复示例内容）。
- **拖动**页面可以改顺序，也可以**拖到别的页面下面变成子页面**。
  拖动时按住鼠标横向移动约 14px 就下沉一级，松手即生效。

删除页面会**连同所有子页面和块一起删除**，不可撤销。

---

## 6. 搜索

点侧边栏顶部搜索框，输入关键词。

- 同时匹配**页面标题**和**块正文**。
- 结果按"最近更新"排序，标题命中和正文命中分开显示。
- 点结果直接跳到对应页面。

---

## 7. AI 助手

点编辑器右上角 ✨ 展开。

- 直接提问，例如「帮我在当前页面写一份周计划」。
- 默认会**自动附带当前页面**（标题 + 每个块的内容和 id），AI 可以直接改你的笔记。
- AI 能调用 7 个笔记工具：列页面、读页面、搜索、建页面、追加内容、改块、删块。
- 流式输出，能看到思考过程、工具调用进度，可以随时点 ■ 中断。

> ⚠️ AI 助手复用本机 `~/.pi/agent` 的模型与凭据配置。没有配置过的话，
> 设置里会显示"没有检测到可用模型"。详见 [AI 排障](../ai/troubleshooting.md)。

---

## 8. 设置

点侧边栏右下角 ⚙ 打开，四个分区：

| 分区 | 能改什么 |
| --- | --- |
| 外观 | 主题（浅色/深色/跟随系统）、正文字号、内容宽度 |
| AI 助手 | 模型选择、自动附带页面、附加指令、重置对话 |
| 数据与存储 | 页面/块数量、数据库路径、图片资源、恢复默认设置 |
| 关于 | 版本、Electron / Chromium / Node 版本、平台 |
